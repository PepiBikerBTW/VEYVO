# VEYVO

VEYVO is a Windows running journal. Log each run's distance, time, and perceived effort (1–10). The app suggests a conservative next easy run using fixed rules. The weekly calendar shows recorded sessions, unavailable days, and the next suggested run. Future workouts are set after you log the result and how you felt.

## Windows

Run `npm start` for development. Run `npm test` for running and clock rules. `npm run build` creates the Windows installer and portable app. Strava import remains available.

The web app and its account sync have been removed. Running data remains local to the Windows app.
